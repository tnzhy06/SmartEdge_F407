# SmartEdge_F407

基于 **立创·梁山派·天空星 `STM32F407VGT6` + `FreeRTOS`（CMSIS-RTOS v2）** 的工业边缘采集网关与本地触控终端，以“工业机柜环境监测与智能通风”为核心演示场景。

## 核心功能特性

- **温湿度现场采集（RS-485 / Modbus RTU 主站）**：通过 `USART2 + DMA + MAX3485E` 周期读取 `KTH2-R` 变送器温湿度（支持负温度补码解析），具备断线告警与自动恢复能力。
- **自动滞回与手动通风控制**：自动模式下默认 `30.0 °C` 启动、`27.0 °C` 停止并支持温差线性调速（`1200–3000 RPM`），传感器失效时自动切入 `1500 RPM` 安全降级通风；手动模式支持启停与 `800–3000 RPM` 转速调节。
- **双路物理 CAN 总线闭环**：片内 `CAN1`（控制主站）与 `CAN2`（模拟风扇节点）分别通过两块外部 `SN65HVD230` 收发器接入同一物理总线，实时识别并区分**风扇堵转、命令超时、节点失联**三类故障。
- **本地触控交互（LVGL v9）**：2.8 英寸横屏 `320×240`（`ST7789 + XPT2046`，`SPI2 DMA` 异步刷屏），提供 `Overview` / `Trend` / `Diag` 纯英文三页面界面及 4 点触摸校准。
- **以太网上位机接入与校时（LwIP）**：基于 `LAN8720 RMII` 提供 `Modbus TCP`（端口 `502`）多连接遥测与远程控制服务，并支持联网 `SNTP` 自动校时与硬件 `RTC` 备用电池断电走时。
- **黑匣子日志、看门狗自恢复与扩展预留**：板载 `SDIO` TF 卡按日期记录 `CSV` 运行日志；独立看门狗（`IWDG ~4 s`）监控 5 个核心任务心跳并结合 `RTC_BKP_DR3` 与 `RCC->CSR` 精准追溯复位与卡死原因；预留 `IAP/OTA` 与低功耗接口桩。

## 开发路线（M1–M5）

- [x] **M1**：STM32CubeMX 原生 CMake 工程骨架、`USART1` CLI 与复位原因检测
- [ ] **M2**：`ST7789` + `XPT2046` + `LVGL v9` 纯英文三页面与 4 点触摸校准
- [ ] **M3**：`RS-485`（`KTH2-R`）采集 + 双路物理 `CAN` 闭环控制与三类故障注入
- [ ] **M4**：`LAN8720` 以太网、`Modbus TCP` 服务与 `SNTP` / `RTC` 校时
- [ ] **M5**：板载 `TF` 卡按日 `CSV` 日志、`Sector 11` 掉电配置、`IWDG` 监督与全量 `AT-01`~`AT-10` 验收
